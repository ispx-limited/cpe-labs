# cpe-labs

Simulate thousands of broadband CPEs, any vendor or model, to test an ACS at
realistic scale without CPE hardware.

## Status

Early development. Nothing is runnable yet; the simulator design is being worked
out. If you operate an ACS and want to influence the direction, open an issue and
describe your setup.
